# Дополнительные эксперименты ЛР 1

Отправленная версия сохранена в коммите `867ab905f167535c3ec08857bc43c67a1eec78cd`.
Её test macro-F1 - 0.6535. Новая работа ведётся локально в `lab1-improvement`.

## Как выбираю улучшение

Все новые кандидаты обучаются и сравниваются только внутри официального train.
Использую два разбиения по авторам: seed 42 и seed 137, по 20% авторов для
валидации. Предсказания разных разбиений зависимы, поэтому не считаю их двумя
независимыми выборками и не объединяю в один доверительный интервал.

Сравнение идёт с отправленной моделью на тех же авторах. Веса смешивания
бустинга и TF-IDF выбираются на seed 42 и применяются на seed 137. Для
нейросети проверяются заранее ограниченные доли 0.1, 0.2, 0.3 и 0.4. Итоговый
кандидат должен улучшать обе валидации относительно отправленной модели.

Текущие реакции используются только как цель обучения. В признаках истории
доступны реакции строго более ранних постов. Начальные пять постов автора
тоже входят в историю. Тесты отдельно проверяют отсутствие влияния текущих
и будущих реакций на текущие признаки.

Официальный test уже оценивался для отправленной версии. В этом раунде он
не используется для выбора кандидатов. После фиксации нового кандидата
допускается одна итоговая оценка на том же test с явным сравнением версий.

## Что проверяю

1. Семантическая история: результат наиболее похожих прошлых постов автора,
   средние реакции с весами по сходству, разброс и доли низких и высоких
   результатов. Все значения сравниваются с обычным уровнем текущего автора.
2. Обучаемый классификатор на полных E5-векторах, профиле, отличии текущего
   текста от истории и числовых признаках. Нормализация обучается на fit-авторах.
3. Дообучение двух верхних слоёв E5 вместе с классификатором текста и контекста.
   Профиль и предыдущие тексты кодируются локально. Нижние слои encoder
   заморожены. Длина текста ограничена 512 токенами.

`experiment_lab1.py`, `experiment_neural.py` и `experiment_finetune.py` запускают
соответствующие проверки. `compare_improvements.py` сравнивает сохранённые
предсказания. Рабочие веса и результаты сохраняются в игнорируемой Git папке
`results/improvement/`.

Дополнительно проверил классы похожих текстов других обучающих авторов.
Все посты текущего автора исключаются из банка соседей. Ни метки валидационных
авторов, ни метки test в этот банк не входят. Проверка есть в `test_neighbors.py`.

## Результат

| Версия | Val seed 42 | Val seed 137 | Официальный test |
|---|---:|---:|---:|
| Отправленная | 0.6662 | 0.6564 | 0.6535 |
| Семантическая история, TF-IDF и две нейросети | 0.6766 | 0.6729 | **0.6593** |

Итоговый QWK - 0.6018, accuracy - 0.6916. Прирост macro-F1 к предыдущей
версии - 0.0058, или 0.58 процентного пункта. 95% парный bootstrap-интервал
прироста по авторам - [0.0014; 0.0102] при фиксированных обученных моделях.

Выбрано смешивание CatBoost с семантической историей, исходной TF-IDF-модели
и среднего двух нейросетей на полных E5-векторах. Доля нейросети - 0.3.
CatBoost переобучен на всём train с 2 162 деревьями; нейросети - на двух эпохах,
с инициализациями 42 и 1042. E5 в выбранной модели заморожен.

Дообучение E5 и поиск по другим авторам не обогнали выбранный вариант по
среднему macro-F1 двух валидаций. Полная таблица сравнений находится в
`submission-v2/validation_experiments.json`. Валидационные оценки после
выбора кандидата могут быть оптимистичными.

## Как воспроизвести

```sh
python -m pip install -r requirements-embeddings.txt
python run_lab1_v2.py --data data
```

Команда проверяет разметку, при необходимости восстанавливает исходную модель,
обучает дополнительные компоненты с параметрами из `submission-v2/selection.json`,
проверяет повторную загрузку и собирает новый комплект. Рабочая модель находится
в `results/lab1-v2/model.joblib`, предсказания и PDF - в `submission-v2/`.

`Lab1_improvement.ipynb` выполнен на официальном наборе. Все 17 623 предсказания
совпадают после сохранения и загрузки модели. Исходные файлы `submission/`
сохранены без изменений. Новый результат остаётся локальным; PR не обновлялся.
